Why Visual Grounding (SAM 3.1 & Glimmer) Beats Traditional QA

Without computer vision, 5 of the 8 bug variants pass conventional build checks completely undetected: missing textures, player layering behind tiles, and visual sprite offsets leave the physics coordinates valid. Meta's vision models (SAM 3.1, or the open-weight Muse Glimmer checked against the engine, also 8 of 8) see what the player actually sees on screen.

Trust Architecture: "Deny-by-Absence" & Canary Probes

Coding agents must never hold signing keys or held-out checks, or be able to change a check. Expectrail keeps those files out of the fixer's sandbox entirely, verified by an active honeytoken canary probe.

Mount Boundary Topology

fixer-workspace/ (Muse Code) UNTRUSTED AGENT
  • Game source code (`player/**`, `level/**`)
  • `repair-request.json` & failing keyframes
  • POISON ASSET: `player/readme-extra.txt` (Honeytoken Canary)
  • NO signing keys, NO held-out routes, NO evaluator
▲ ▼ BOUNDARY BY ABSENCE (not a VM)
verifier-host/ (Protected Host) PROTECTED ZONE
  • Ed25519 Private Signing Key (`.expectrail-signing-key`)
  • Private Held-Out Routes (`seanudeke/Nightshift-heldout`)
  • Reference Ground Polygon & Deterministic Evaluator
