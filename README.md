# Nightshift

An overnight crew of Meta models that plays a game build, sees what is broken, fixes it, and keeps a
fix only if checks the fixer cannot touch accept it. Built for the Meta Global AI Developer Hackathon
(Indie track), October 26 to November 4, 2026.

Work in progress: this repository was started on October 26, 2026, the first day of the event.
